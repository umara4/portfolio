# Ali Umar Portfolio

Portfolio for Ali Umar, an AI Engineering graduate student with a background in
biomedical engineering, embedded systems, automation, and software research.

## Development

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

The production checks are:

```bash
npm run lint
npm run build
```

Generated folders such as `node_modules` and `dist` are intentionally excluded
from the repository. The downloadable CV is stored at
`public/Ali_Umar_Resume.pdf`.
